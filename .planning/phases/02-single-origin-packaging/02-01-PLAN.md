Four constraints on Edit B, each of which has a specific failure mode behind it:

  1. Do **not** call `MapStaticAssets()`. It serves only files present in a manifest generated

     `DirectoryNotFoundException` at host build time and fails the whole test class.

     default pattern already loses to every other matched endpoint, which is what keeps a
     mistyped API path returning a real 404 instead of the SPA shell with status 200.
  4. Do **not** add `UseDefaultFiles()` or a directory-browser middleware. The root path is
     already covered: the fallback matches the empty path and returns `index.html`.
