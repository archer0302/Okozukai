<objective>
Restore development parity after plan `02-01` made the axios client origin-relative. The Vite dev
server gains a `/api` proxy (D-06), the AppHost stops injecting a frontend API URL that nothing
reads any more, and the three documents that still instruct a reader to configure one are
corrected.

Purpose: with no absolute base URL, `aspire run` and `npm run dev` have no bridge between the
dev server on one port and the API on another. The proxy is that bridge, and it is also what
keeps the 14 Playwright E2E tests passing without editing a single test file.

Output: a `server.proxy` entry in `vite.config.ts` pointed at the *observed* Aspire
service-discovery variable, an AppHost with both injections removed and `apiPort` intact, and
agent-facing documentation that describes one origin.
</objective>
